Welcome to S.N-N. UI Library

A UI library for Roblox LocalScripts. Describe your interface as a Lua string and S.N-N. UI Library builds the tabs, controls and live-updating tables for you.

Where to go

How functions are listed

Functions use the format return_type function_name(argument_type argument_name).

table Get(string name)

Wherever a variable is needed, the examples fetch it with Get("Name")[tabNumber].

Installation

S.N-N. UI Library runs inside a LocalScript and ships as a ModuleScript named Lib.

Setup

  • Insert the S.N-N. UI Library ModuleScript as a child of your LocalScript.
  • Name it Lib.
  • Require it from the LocalScript.

Requiring the library installs Wrap_, Unwrap_, Get and BindKey into the LocalScript's environment. Call them directly, with no import.

Example

local ModuleLib = script:WaitForChild("Lib", math.huge)
local Lib = require(ModuleLib)

-- Get is now available with no import
print(Get)

Quick start

Write your layout as a string, pass it to Lib.NewUI, then use the returned table.

table Lib.NewUI(string layout)

The returned table is indexed by tab name, like MainUI["Tab1"], to reach that tab's events.

Example

local Lib = require(script:WaitForChild("Lib", math.huge))

local Layout = [[{
	["~!Config"] = {
		["Title"] = "My UI Library",
		["Toggle"] = Enum.KeyCode.Equals
	},
	["Tab1"] = {
		["Title"] = "!^ Hello",
		["Button"] = "!B Click me",
		["Toggle"] = "!T(false) Enable"
	}
}]]

local MainUI = Lib.NewUI(Layout)

local Button = Get("Button")[1]

Button.Activated:Connect(function()
	print("clicked!")
end)

Layout syntax

Every value in your layout string can start with a special command that tells the library what to create.

Tab commands

CommandDescription
~!Creates a config for the UI. Without it, the key just creates a new tab. Example: ["~!Config"]

Text commands

CommandDescription
!^Creates a title with the text after the command.
!@Creates a description with the text after the command.

Class commands

Controls use the form ![Class]. The list is on the Components page.

Tabs are ordered as they appear in your editor, top to bottom. The first tab is [1], the second [2], and so on. Get and BindKey rely on this.

Example

local MainUI = Lib.NewUI([[{
	["~!Config"] = {
		["Title"] = "Syntax demo"
	},
	["Tab1"] = {
		["Heading"] = "!^ I am a title",
		["About"] = "!@ I am a description",
		["Go"] = "!B Press me"
	},
	["Tab2"] = {
		["Go"] = "!B Press me too"
	}
}]])

-- "Go" exists in both tabs, so pick one by tab number
local FirstGo = Get("Go")[1]
local SecondGo = Get("Go")[2]

Components

Each control is a string with a class letter, optional arguments and a label.

ClassControlSyntax
BButton"!B MyButton"
T(bool)Toggle. Defaults to false."!T(true) MyToggle"
"!T MyToggle"
DDropdown"!D MyDropdown"
{"!D", {"Option1", "Option2"}}
I(string|number)[start]Input textbox that accepts only the chosen type."!I(string)[wow text] Name"
"!I(number)[1234] Amount"
K(key)Keybind"!K(Equals) MyKeybind"
"!K(MouseButton1) MyKeybind"
C(R, G, B)Color. Defaults to white."!C(255, 0, 0) MyColor"
"!C MyColor"

Example

local MainUI = Lib.NewUI([[{
	["Tab1"] = {
		["Button"] = "!B I am a button",
		["Toggle"] = "!T(false) I am a toggle",
		["Dropdown"] = "!D I am a dropdown",
		["Color"] = "!C(255, 0, 0) MyColor",
		["Text"] = "!I(string)[wow text] Name",
		["Amount"] = "!I(number)[1234] Amount",
		["Keybind"] = "!K(Equals) MyKeybind"
	}
}]])

local Button = Get("Button")[1]
local Dropdown = Get("Dropdown")[1]

Button.Activated:Connect(function()
	table.insert(Dropdown, "Option4")  -- adds an option
end)

MainUI["Tab1"].Changed:Connect(function(property, new, old)
	print(property, new, old)          -- toggle, color, input...
end)

BindKey("Keybind", 1, function(action, processed)
	print(action, processed)
end)

Config

A table with the ~! prefix customizes the UI as a whole.

KeyTypeDescription
Screen_ScaleUDim2Size of the UI on screen.
TitlestringTitle shown on the UI.
ToggleEnum.KeyCodeKey that shows or hides the UI.

Example

local MainUI = Lib.NewUI([[{
	["~!Config"] = {
		["Screen_Scale"] = UDim2.new(1, 0, 1, 0),
		["Title"] = "My UI Library",
		["Toggle"] = Enum.KeyCode.Equals
	},
	["Tab1"] = {
		["Title"] = "!^ Press = to hide me"
	}
}]])

Environment functions

Installed into your LocalScript's environment when the library loads.

Wrap_

handle Wrap_(any value)

Keeps a handle to a value without it appearing in garbage collection. It works like cloneref, but is made for developers and isn't an exploit. Functions and events can be used directly on the handle.

Unwrap_

any Unwrap_(handle handle)

Unwraps a handle so the official Roblox Lua engine can understand it. Use it before passing a wrapped value to Roblox APIs.

local hidden = Wrap_(workspace.Baseplate)

-- unwrap inline, right where it is used
child.Value = Unwrap_(hidden)

Never store the result of Unwrap_ in a variable. See Using Wrap_ and Unwrap_ safely.

Get

table Get(string name)

Finds every variable in the layout table whose name matches. Results are in tab order: [1] is the first tab, [2] the second, and so on. The library orders tabs top to bottom as written in your editor.

local Button = Get("Button")[1]    -- "Button" in the first tab
local Keybind = Get("Keybind")[2]  -- "Keybind" in the second tab

BindKey

connection BindKey(string name, number tabOrder, function callback)

Takes a variable name and a tab order, finds that tab, and checks the variable exists there. The callback acts like both InputBegan and InputEnded.

Callback argumentDescription
action"Began" or "Ended"
gameProcessedWhether the game already handled the input.
BindKey("Keybind", 2, function(action, processed)
	print(action, processed, Get("Keybind")[2])
end)

Using Wrap_ and Unwrap_ safely

A wrapped object is hidden. The moment you unwrap it, the real object exists in your script, and anything that holds it can be seen in garbage collection.

The rules

  • Keep the handle from Wrap_ in your variables. Never keep the raw object.
  • Call functions and connect events straight on the handle. Use Unwrap_ only when you set a property or pass the real object somewhere, and do it inline in that statement.
  • Never store the result of Unwrap_ in a local, a table or an upvalue.
  • Never yield while an unwrapped object is alive. A yield gives the garbage collector enough time to register it.

Don't keep the raw object

local hidden = Wrap_(part)

-- BAD: the raw object now lives in a local variable
local raw = Unwrap_(hidden)
raw.Name = "Visible"

Unwrap inline instead

Pass Unwrap_(hidden) straight into the property or argument that needs it. Nothing is left behind afterwards.

local hidden = Wrap_(part)

child.Value = Unwrap_(hidden)
highlight.Adornee = Unwrap_(hidden)
weld.Part1 = Unwrap_(hidden)

Don't yield while unwrapped

If the raw object is alive during a wait, the garbage collector can register it. Do your waiting first, then unwrap and use it in one go.

local hidden = Wrap_(part)

-- BAD: raw object is alive for the whole wait
local raw = Unwrap_(hidden)
task.wait(1)
raw.Name = "Late"

-- BAD: the unwrapped argument is held until the delay finishes
task.delay(1, function(obj) obj.Name = "Late" end, Unwrap_(hidden))
local hidden = Wrap_(part)

-- GOOD: wait first, unwrap only at the moment of use
task.wait(1)
child.Value = Unwrap_(hidden)

-- GOOD: unwrap inside the delayed function
task.delay(1, function()
	highlight.Adornee = Unwrap_(hidden)
end)

Calling functions and events

You don't need to unwrap an object or service to call its functions or connect to its events. Use them directly on the handle. Wrapping works like cloneref, but it is made for developers and isn't an exploit.

local hidden = Wrap_(part)

hidden:Destroy()
print(hidden:GetFullName())

Events work the same way. You can connect to them while the object or service is still wrapped.

local UserInputService = Wrap_(game:GetService("UserInputService"))
local key = Enum.KeyCode.E

UserInputService.InputBegan:Connect(function(input, gameProcessed)
	if gameProcessed then return end
	if input.KeyCode == key or input.UserInputType == key then
		print("key pressed")
	end
end)

Editing properties

To edit properties of the object, unwrap it, and do it inline. The object is unwrapped, edited and gone within the same statement.

local hidden = Wrap_(part)

Unwrap_(hidden).Name = "Renamed"
Unwrap_(hidden).Transparency = 0.5

Using services

The same pattern works for services such as CoreGui, UserInputService and ReplicatedStorage. Wrap the service once. Call its functions directly, and unwrap it inline only when you need to set a property or pass it somewhere.

local CoreGui = Wrap_(game:GetService("CoreGui"))
local UserInputService = Wrap_(game:GetService("UserInputService"))
local ReplicatedStorage = Wrap_(game:GetService("ReplicatedStorage"))

-- parent a gui into CoreGui
screenGui.Parent = Unwrap_(CoreGui)

-- edit a service property inline
Unwrap_(UserInputService).MouseIconEnabled = false

-- functions and events work on the handle, no unwrap needed
ReplicatedStorage:WaitForChild("Remote", math.huge)

Example

local Button = Get("Button")[1]
local hidden = Wrap_(workspace:WaitForChild("Baseplate", math.huge))

Button.Activated:Connect(function()
	-- no locals, no yields: unwrap and use in a single statement
	highlight.Adornee = Unwrap_(hidden)
end)

Events

Controls and tabs expose events you connect to with :Connect.

Activated

event Button.Activated()

Fires when a button is pressed.

local Button = Get("Button")[1]

Button.Activated:Connect(function()
	print("hello world!")
end)

Changed

event Tab.Changed(string property, any new, any old)

Available on each tab, like MainUI["Tab1"].Changed. Fires when a value is edited, including toggles, colors and other controls.

ArgumentDescription
propertyWhat was edited.
newThe new value.
oldThe value before the change.
MainUI["Tab1"].Changed:Connect(function(property, new, old)
	print(property, new, old)
end)

Disconnecting

onWrite, Changed, BindKey and other event connections can be disconnected.

local Dropdown = Get("Dropdown")[1]

local changedConn = MainUI["Tab1"].Changed:Connect(function() end)
local writeConn = Dropdown.onWrite:Connect(function() end)
local keyConn = BindKey("Keybind", 2, function() end)

changedConn:Disconnect()
writeConn:Disconnect()
keyConn:Disconnect()

Dropdowns

A dropdown is a live table. Write to it like any Lua table and the UI follows.

onWrite

event Dropdown.onWrite()

Fires every time data is added, changed or removed, through table.insert or direct assignment.

local Dropdown = Get("Dropdown")[1]

Dropdown.onWrite:Connect(function()
	print("changed!", Dropdown)
end)

Writing

local Dropdown = Get("Dropdown")[1]

table.insert(Dropdown, "123")
table.insert(Dropdown, workspace)

Dropdown["manualwrite"] = true
Dropdown[12] = "numnum"

Dropdown["manualwrite"] = false   -- change
Dropdown["manualwrite"] = nil     -- remove

Reading

Dropdowns work with pairs, ipairs and next.

local Dropdown = Get("Dropdown")[1]

for key, value in pairs(Dropdown) do
	print(key, value)
end

Full example

A complete LocalScript using every major feature.

local ModuleLib = script:WaitForChild("Lib", math.huge)
local Lib = require(ModuleLib)

local MainUI = [[{
	["~!Config"] = {
		["Screen_Scale"] = UDim2.new(1, 0, 1, 0),
		["Title"] = "My UI Library",
		["Toggle"] = Enum.KeyCode.Equals
	},
	["Tab1"] = {
		["Title"] = "!^ I am a title",
		["Description"] = "!@ My sole purpose is a description",
		["Button"] = "!B I am a button",
		["Toggle"] = "!T(false) I am a toggle",
		["Dropdown"] = "!D I am a dropdown",
		["Color"] = "!C(255, 0, 0) MyColor",
		["Input"] = "!I(string)[wow text] accepts only strings",
		["Input2"] = "!I(number)[1234] accepts only numbers"
	},
	["I am Tab"] = {
		["Random"] = "!^ WOW!",
		["PrintB"] = "!B print hello world!",
		["Keybind"] = "!K(Equals) MyKeybind",
		["Dropdown"] = "!D behold the dropdown"
	}
}]]

MainUI = Lib.NewUI(MainUI)

local Button = Get("Button")[1]
local Keybind = Get("Keybind")[2]
local Dropdown = Get("Dropdown")[1]

BindKey("Keybind", 2, function(action, processed)
	print(action, processed, Keybind)
end)

Button.Activated:Connect(function()
	print("hello world!")
end)

MainUI["Tab1"].Changed:Connect(function(property, new, old)
	print(property, new, old)
end)

Dropdown.onWrite:Connect(function()
	print("changed!", Dropdown)
end)

table.insert(Dropdown, "123")
Dropdown["manualwrite"] = true
Dropdown["manualwrite"] = nil
